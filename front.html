🔒 Plugin Security

Code Audit: Scans plugin source for dangerous patterns (shell exec, eval, ctypes, etc.) before loading.
Import Restriction: Limits which Python modules plugins can import. "Strict" allows only json, re, datetime, etc.
When enabled, plugins must declare required capabilities (process, network, file_write, file_read) in their manifest.json → permissions field.
Restrict CPU time (30s) and memory (512MB) per plugin during loading. Uses OS-level limits (Unix: setrlimit; Windows: best-effort).
